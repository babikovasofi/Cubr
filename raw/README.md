# raw/ — unsorted inputs (drop zone)

Dump everything here in any format: ТЗ (docx/md/txt), pasted chat messages,
meeting recordings, presentations, user story maps, C4 sketches. Do **not**
sort or clean it — that's the agent's job later.

When you're ready, ask the agent:
> "Read everything in raw/, analyze it, and record it consistently into the
>  Memory Bank. Then remove the raw files you've fully absorbed."

startpoint intentionally does **not** ingest raw/ — it only builds the empty
skeleton.
