# Plan: Этап 0 — прототип зрения   (slug: stage0-vision-prototype)

> Источник: planner + skeptic (сквозь Cubr:plan). Skeptic verdict = **revise**;
> его HIGH/MED правки вложены ниже. Открытое решение для человека — в **Blockers**.

## TL;DR
Грязный одностраничный браузерный прототип в `/prototype` (без бэка/дизайна),
доказывающий, что зрение работает: камера + MediaPipe Hands (зоны → неподвижность
→ FSM → мини-таймер) и чтение кубика (рамка-гид, сетка 3×3, калибровка по
собранному кубику, Lab/ΔE, квоты 9×6, сверка с эталоном скрамбла через cubejs).
Модули названы под `vision/*` Этапа 1 — дешёвый порт. **Гейт: точность чтения
≥90% при норм. свете, измеренная против cubejs-эталона (не «на глаз»), по-стикерно,
на ≥2 кубиках.** Провал гейта — валидный, запланированный исход (риск-киллер R1),
не баг: стоп и пересмотр подхода, не идём в Этап 1.

## Acceptance criteria (что проверяет /review)
1. **Полный мини-цикл с одной страницы:** калибровка (6 собранных граней → 6
   эталонных цветов) → скрамбл на экране → перемешал → чтение 6 граней → cubejs
   сверяет прочитанное состояние == эталон скрамбла → руки в зоны → READY → убрал
   руки → таймер пошёл → собрал → руки в зоны → таймер стоп → чтение 6 граней →
   подтверждение сборки. Несовпадение называет конкретную грань/позицию.
2. **FSM рук наблюдаема и устойчива:** `NO_HANDS → HANDS_IN_ZONE → READY → SOLVING
   → STOPPED` + путь **ABORT/reset** (детект рук потерян > T в READY/SOLVING →
   сброс, цикл не заклинивает). Дебаунс на КАЖДОМ переходе, включая leave-события
   (N подряд кадров/мс), не только на входе. Правило старта задано явно (первая
   рука покинула зону vs обе). «Рука ушла из зоны» отличается от «детекция
   потеряна» (граб кубика). Пороги — в одном config-объекте.
3. **Неподвижность масштабо-инвариантна:** метрика движения нормирована на размер
   руки (нормализованные координаты MediaPipe 0..1 ИЛИ дистанция landmark 0↔9),
   порог задан как доля размера руки, не сырые пиксели.
4. **Таймер на ОДНИХ часах:** `performance.now()`-домен. Момент события берётся из
   DOMHighResTimeStamp коллбэка `requestVideoFrameCallback` (тот же timebase, что
   `performance.now()`); `mediaTime` НЕ мешать. `getUserMedia` просит `frameRate
   ideal 60`. Таймер не привязан к кадрам.
5. **Чтение грани:** рамка-гид оверлей → область в canvas → 3×3 → цвет ячейки =
   `argmin ΔE(Lab(медиана центральных 50% пикселей), ref_i)` по 6 эталонам.
   **ΔE = CIEDE2000 с самого начала** (через config-флаг; CIE76 слаб именно в
   красный↔оранжевый/белый↔жёлтый — не тратить цикл гейта на его провал).
6. **cubejs — явное соответствие facelet:** строка facelet в порядке **URFDLB**;
   в плане/коде зафиксировано: с какого угла начинается index-0 каждой грани и
   направление скана; протокол захвата фиксирует ориентацию (оверлей помечает
   верх/U-ребро, промпт говорит какая грань «фронт» и куда верх); нормализация
   поворота грани (0/90/180/270) перед маппингом; центр-стикер каждой грани
   определяет её цвет и авто-ориентирует (не доверять «на глаз»). Юнит-тест:
   известный скрамбл → руками собранная facelet-строка → `cubejs` парсит/solvable
   И равна ожидаемой (доказывает маппинг индексов).
7. **Квоты 9×6 дают ВАЛИДНЫЙ куб:** сначала пинуем 6 центров к их цвету грани
   (центры однозначны, задают схему) и убираем из пула → жадное назначение
   остальных 48 (сорт пар по ΔE, скип исчерпанных квот-9) → **валидация результата
   через cubejs** (каждый цвет ровно 9, строка парсится). Невалидно → **FAIL LOUD**,
   не молчать. Жадность МОЖЕТ не собрать — это наблюдаемый data-point. Fallback:
   венгерский алгоритм (~50 строк) если жадность мимо гейта.
8. **Гейт точности — независимое измерение (не самоподтверждение):** harness
   применяет случайный скрамбл → тестер физически ставит кубик → чтение → сравнение
   с **cubejs-эталоном** (ground truth из известного скрамбла, НЕ с глаз тестера).
   Считать **по-стикерно из 54** + отчёт confusion-матрицы по цветам (особ.
   красный↔оранжевый, белый↔жёлтый), не только pass/fail грани (all-9-match прячет
   одиночные ошибки и завышает число). PASS ⇔ ≥90% стикеров верны при норм. свете
   на **≥2 кубиках**; результат печатается страницей.
9. **Sanity-гейт перед чтением:** если `ΔE(red,orange)` эталонов < порога или
   средняя яркость кадра вне диапазона → просить сменить свет, а не читать. Re-чек
   per-face во время 6 захватов: дрейф центров грани от калибровки > порога →
   reject+reprompt грани (свет мог измениться посреди серии).

## Plan (шаги + файлы + тесты)

**Тулчейн (РЕШЕНО):** **Vite + TypeScript**. Пакеты через npm (не CDN):
`@mediapipe/tasks-vision` (**HandLandmarker** — актуальный API; legacy
`@mediapipe/hands` устарел), `cubejs`. Скаффолд `npm create vite@latest prototype
-- --template vanilla-ts` (без React — прототип throwaway, DOM руками). HMR для
живого тюнинга CV-порогов. Тесты — **Vitest** (`*.test.ts`). Порт в Этап 1
бесплатный (тот же тулчейн).

Файлы под `prototype/` — расширения **`.ts`** (ниже показаны как `.js`/`.mjs` для
краткости; реально `.ts`). Модули названы как `vision/*` Этапа 1 для дешёвого порта:
- `config.js` — все пороги: `ZONE_ENTER_MS=200, STILL_MS=500, STOP_MS=200,
  LEAVE_DEBOUNCE_MS, ABORT_MS`, порог движения **как доля размера руки**, гео
  рамки-гида, доля центр-области 0.5, quota=9, порог ΔE(red,orange), `dE=ciede2000`.
- `camera.js` — `getUserMedia({video:{frameRate:{ideal:60}}})`, bind `<video>`,
  цикл `requestVideoFrameCallback` отдаёт `{frame, nowTs}` (now-домен), ошибки
  камеры (нет доступа/нет камеры/занята). **Детекция на не-зеркаленном кадре,
  зеркалим только дисплей.**
- `hands.js` — MediaPipe **HandLandmarker** (`@mediapipe/tasks-vision`, npm, пин
  версии + wasm/`.task`-модель), 21 landmark/рука, рисует landmarks+зоны+рамку на
  оверлее, `bothInZone` (ладони 0,9), масштабо-инвариантная метрика неподвижности.
  **Handedness для сырого кадра — флипнуть подпись для зеркального UI.**
- `fsm.js` — чистый КА с дебаунсом на всех переходах (вкл. leave), путь ABORT/reset,
  явное правило старта, различение «ушла из зоны» vs «детекция потеряна». Без DOM.
- `colors.js` — `rgb2lab`, `deltaE` (**CIEDE2000**, CIE76 за флагом),
  `medianOfCentralRegion`, `calibrate(6 граней→6 refs)`, `classifyFace`,
  `assignQuota` (центры-пин → жадное 9×6). Чистые функции.
- `cube.js` — гео рамки-гида, извлечение области в work-canvas, 3×3, семпл 9 ячеек,
  **нормализация поворота грани по центру**.
- `cubeState.js` — обёртка cubejs: случайный скрамбл; solved-cube применить скрамбл
  → эталонные facelets (**URFDLB, зафиксированный маппинг**); сравнение прочитанного
  vs эталон → список отличий по грани/индексу; **валидация legal-строки**.
- `main.js` — оркестрация всего цикла + рендер статуса/таймера/отчёта/результата.
- `accuracy.js` — harness: скрамбл → чтение → сравнение с cubejs-эталоном,
  per-sticker счёт из 54 + confusion по цветам, печать ≥90% pass/fail.
- `tests/colors.test.mjs` — `node:test`: rgb2lab (известные значения), deltaE
  (симметрия, ноль на равенстве), quota на 54 синтетических Lab с неоднозначными
  red/orange → ровно 9×6 И квота чинит red/orange vs наивный argmin; центр-пин.
- `tests/fsm.test.mjs` — `node:test`: неподвижность <500мс не даёт READY; ≥500мс
  даёт; уход руки в READY → solve_start; обе в зоне ≥200мс в SOLVING → solve_stop;
  дебаунс гасит 1-кадровый дропаут; ABORT по потере детекции.
- `tests/cubestate.test.mjs` — **новый (skeptic HIGH#2)**: известный скрамбл →
  руками facelet-строка → cubejs solvable И == ожидаемой (доказывает маппинг).
- `README.md` — как запускать (`npx serve prototype` / `python -m http.server`),
  как гонять harness, как юнит-тесты (`node --test prototype/tests`), тюнинг-ручки,
  дисклеймер «грязный прототип».
- `TODO.md` (корень) — APPEND «Сейчас (этап 0)» чеклист зеркалит workplan 0.1/0.2/0.3.

**Порядок работы:** config → camera → hands → fsm → colors → cube → cubeState →
main → accuracy → тесты → README/TODO → ручной проход 0.3 (3 света × ≥2 кубика ×
1–2 человека; harness при норм. свете; <90% честно → ГЕЙТ, стоп).

**Тесты:** юнит (`node --test`) на colors/fsm/cubestate; ручное — FSM+таймер (убрал
руки→пошёл, вернул→стоп, 1-кадровый флик не триггерит), чтение (калибровка→знакомая
грань, скрамбл→сверка pass/fail с названной гранью), гейт точности per-sticker vs
cubejs на 2 кубиках, sanity-гейт по яркости/ΔE.

## Assumptions
- cubejs через CDN UMD для скрамбл→эталон и сравнения; min2phase в Этапе 0 не нужен
  (сборку не решаем, только применяем скрамбл + сравниваем).
- «точность ≥90%» уточнена skeptic'ом → **per-sticker из 54** (не face-all-9-match),
  ground truth из cubejs (не с глаз), ≥2 кубика. DoD стадии НЕ закрыт, пока не
  пройдена и матрица 0.3 (3 света × 2 кубика × 1–2 человека).
- Прототип таргетит desktop Chrome (rVFC поддержан; R8 = MVP desktop). Fallback на
  `requestAnimationFrame` только если понадобится, с пометкой о потере точности.
- Рамка-гид — фиксированный прямоугольник (MVP П2); тестер сам сажает кубик ровно.
- Жадность 9×6 для Этапа 0; венгерский — fallback при промахе гейта.
