# План — стрики ежедневных серий (V3 «Цели и стрики»)

Опирается на уже готовый «скрамбл дня» (`daily_challenges` / `daily_attempts`).
Причина взять именно это: серия — единственный дешёвый механизм возврата,
который не требует ни рейтинга (его нет и не будет до честностного кирпича),
ни соперника, ни новых данных.

## Решение: стрик ВЫВОДИМ, не храним

Ни таблицы, ни колонки, ни миграции: серия = производная от дат в
`daily_challenges`, где у пользователя есть завершённая попытка. Тот же приём,
что в воронке (`services/funnel.py`).

Плюс: невозможно «рассинхронить» счётчик (нет счётчика), нет джобы, которая
чинит серии, и переписывание правил не требует бэкфила.
Минус: запрос на каждый показ — на масштабе одного человека это десятки строк.

## Что считается днём серии

Попытка **завершена человеком**: `status == "valid"`, либо `status == "dnf"`
c непустым `submitted_at` (честный DNF — это тоже пройденный ритуал).
**Не считается** брошенная попытка (`started`, добитая свипом в `dnf` без
`submitted_at`) — иначе серию можно было бы «набивать» нажатием start.

## Правило серии

- `current_streak` — непрерывная цепочка дней, заканчивающаяся **сегодня или
  вчера** (UTC-дни, как и весь daily-вертикал). День ещё не закончился, поэтому
  вчерашняя цепочка считается живой: `completed_today=false` — это «серия под
  угрозой», а не «серия сгорела».
- Цепочка старше вчера → `current_streak = 0`.
- `best_streak` — максимальная цепочка за всю историю (≥ current).

## Эндпоинт

`GET /daily/streak`, authed (аноним 401), read-only, БЕЗ скрамбла (П8 не трогаем).
`DailyStreakRead`: `current_streak`, `best_streak`, `completed_today`,
`last_day` (ISO-дата или null), `today`.

## Фронт

- `api/daily.ts`: `getDailyStreak()`.
- Компонент `daily/StreakBadge.tsx` — строка «5 дней подряд · рекорд 9» + честный
  статус: сделал сегодня / сегодня ещё нет / серии нет. Без огня-эмодзи (§UI: эмодзи
  из интерфейса выпилены), акцент — наклейка в цвете `live`, как у остальных daily.
- Показ на `/daily` (над бордом). Профиль — вне скоупа, чтобы не тащить ещё один
  запрос на страницу, где уже три.

## Test plan

- `tests/test_daily_streak.py`: пусто → нули; сегодня → 1/1/true; вчера → 1/1/false
  (серия жива); позавчера → 0, best=1; 3 дня подряд заканчивая сегодня → 3;
  разрыв 5-дневной старой цепочки и новой 2-дневной → current=2, best=5;
  брошенная попытка (`dnf` без `submitted_at`) не входит; попытки другого юзера
  не влияют; аноним → 401.
- frontend: `tests/daily/streak.test.ts(x)` — маппинг API + рендер трёх состояний
  (нет серии / серия сегодня закрыта / серия под угрозой).
- Регресс: весь backend pytest + ruff/mypy; весь frontend vitest + tsc/lint/build.
