## Решения, которые стоит помнить

- **Гейт рендерится ВМЕСТО детей**, а не поверх: иначе камера/WS ритуала успели бы
  подняться под заглушкой (тот же приём, что монтирование `ActiveRitual` только после
  commit в турнире).
- **Детекция без ширины экрана.** Узкое окно на десктопе — не телефон; resize/поворот
  не должны выбивать из активной сборки. Ноут с тачскрином даёт `hover: hover` → проходит.
  Планшет даёт `hover: none` → гейтится (ритуал на нём так же неудобен).
- **Media-запрос авторитетнее UA** — iPadOS с «десктопным» UA ловится корректно.
  Сломанный `matchMedia` не гейтит вслепую: падаем в UA-фолбэк.
- **Копируется `location.href`, а не origin**: приглашение в дуэль без токена бесполезно,
  человек переносит на компьютер ту же ссылку, по которой пришёл.
- **Что НЕ гейтим:** лендинг, `/rules`, `/privacy`, вход/регистрация, `/onboarding`
  (в нём «пропустить» и настройки профиля — иначе свежезарегистрированный мобильный
  юзер заперт), `/profile`. С телефона читают и заводят аккаунт, собирают за компьютером.
- Формулировка совпала с уже написанным в `RulesPage` («Мобильные браузеры не
  поддерживаются») — новых обещаний тексты не дают.
