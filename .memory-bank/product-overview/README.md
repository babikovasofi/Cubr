# Product Overview — Cubr

> Краткая ориентировка. Мастер-документ — [vision.md](vision.md).
> Связанное: [risks.md](risks.md), [roadmap.md](roadmap.md).

- **Что делает:** веб-платформа, где спидкуберы соревнуются онлайн; камера +
  компьютерное зрение заменяют судью (проверка скрамбла, старт/стоп по рукам,
  подтверждение сборки).
- **Кому:** спидкуберам, от новичков до продвинутых; старт — рунет-сообщество.
- **Ключевая ценность:** честная онлайн-дуэль без живого судьи + приватность
  (видео не покидает устройство, на сервер — только кадры-доказательства).
- **Цель:** реальный задеплоенный продукт, которым пользуются живые люди.
- **Вне scope MVP:** плей-офф сетки, соцсеть (друзья/лента/ЛС), реплеи чужих
  сборок, другие головоломки (2×2/4×4/пирамидка), мобильное приложение. → [roadmap](roadmap.md).

## MVP — состав

**Режимы:**
- **Дуэль · Фаст** — 1 сборка, оба онлайн, один скрамбл на двоих.
- **Дуэль · Классика (Ao5)** — 5 сборок, WCA-average (отбрасываются лучшее/худшее).
- **Еженедельный турнир** — одна сборка на общем скрамбле недели, общая таблица.
- **Дуэль по ссылке с другом** — кандидат в MVP (решает холодный старт; см. R5).

**Кубки:** единая валюта рейтинга; матчмейкинг по похожему числу кубков; режим
«риск» (вызов сильнее — награда выше). Формула баланса — позже.

**Ритуал сборки (ядро продукта):** показывает СОБРАННЫЙ кубик камере (калибровка/быстрая
подстройка + подтверждение честного старта — **первым, до скрамбла**) → скрамбл от сервера →
игрок мешает → показывает перемешанный кубик (сверка с эталоном) → две руки на стол (готовность) →
синхронный старт → собирает → руки на стол (стоп) → показывает кубик (подтверждение) →
результат. Соперника видно только статусом, не видео. Скрамбл показывается
**визуальными пошаговыми инструкциями** (картинки-со-стрелками, по умолчанию) или
нотацией — по выбору игрока ([feature-scramble-visual](feature-scramble-visual.md)). Цвета —
из **профиля кубика** с быстрой подстройкой одной гранью ([feature-cube-profiles](feature-cube-profiles.md)).

**Аккаунты:** регистрация обязательна; email+пароль (подтверждение, восстановление)
+ Google OAuth. Профиль: ник, аватар, кубки, рекорды (сингл/Ao5), история.

**Честность (критично):** скрамбл генерит только сервер; ключевые кадры уходят на
сервер для повторной проверки; сервер валидирует последовательность и тайминги
событий; результат засчитывается только после серверной валидации. Цель —
сделать чит **дорогим**, не «невозможным».

## Определение успеха
Продукт по публичной ссылке; реальные люди (не только автор) проводят дуэли и
участвуют в турнире недели; зрение обслуживает полный ритуал при обычном свете.
