# Cubr — Roadmap (будущее после MVP)

> Бэклог идей, НЕ обязательство. Правило проекта: сначала MVP, новые фичи — только когда предыдущий этап работает.

**Обозначения сложности:** 🟢 просто · 🟡 средне · 🔴 сложно/исследовательски
**Ценность:** ⭐ приятно · ⭐⭐ заметно · ⭐⭐⭐ фича-визитка

---

## V2 — «Продукт, за которым возвращаются»
Цель: удержание и первые фичи, которых нет у обычных таймеров.

| Фича | Сложн. | Ценность | Комментарий |
|---|---|---|---|
| **Дуэль по ссылке с другом** | 🟢 | ⭐⭐⭐ | Решает холодный старт. Кандидат вообще в MVP |
| Ачивки и бейджи | 🟢 | ⭐⭐ | «Первая победа», «sub-30», «10 дуэлей», «гроза авторитетов» |
| График прогресса времени в профиле | 🟢 | ⭐⭐ | Простая линия по истории сборок |
| Звуки отсчёта (StackMat-сигнал) | 🟢 | ⭐ | Куберы привыкли к нему на реальных стартах |
| Ежедневный скрамбл дня | 🟢 | ⭐⭐ | Один на всех, мини-конкурс, повод заходить каждый день |
| h2h-история встреч | 🟡 | ⭐⭐ | «Вы играли 12 раз, счёт 7:5» |
| Реванш-серии | 🟢 | ⭐ | Уже частично в userflow |
| Красивая карточка результата для соцсетей | 🟡 | ⭐⭐ | Органический маркетинг — люди сами репостят |

## V3 — «Тренажёр и соцсеть»
Цель: причина пользоваться именно твоим сайтом + сетевой эффект.

| Фича | Сложн. | Ценность | Комментарий |
|---|---|---|---|
| **Разбор сборки по фазам (крест→F2L→OLL→PLL)** | 🔴 | ⭐⭐⭐ | **ФИЧА-ВИЗИТКА.** Невозможна на обычных таймерах, чисто твоя ML-зона. Показывает, где теряется время |
| Тренажёр конкретных случаев (OLL/PLL) | 🟡 | ⭐⭐ | Генерация скрамблов под нужный кейс |
| Личный «коуч»-аналитика | 🟡 | ⭐⭐ | «F2L стабильный, PLL проседает на 2 сек» |
| Цели и стрики | 🟢 | ⭐⭐ | ✅ целиком: ежедневная серия (`GET /daily/streak`) + цели sub-N с «5 подряд под рубежом» (`profile/goals.ts`, из истории, без БД) |
| Лента событий + реакции | 🟡 | ⭐⭐ | «Аня побила рекорд!» — ядро соцсети |
| Друзья и подписки | 🟡 | ⭐⭐ | Вызов друга в один клик |
| Профиль-витрина | 🟢 | ⭐ | ✅ метод + год начала (миграция 0010), кубики и бейджи в профиле уже были; публичной витрины нет by design (П10) |
| Клубы/команды (напр. по вузам) | 🟡 | ⭐⭐ | Тебе близко, даёт групповую мотивацию |

## V4 — «Большая лига»
Цель: удержание надолго, масштаб, выход за рунет.

| Фича | Сложн. | Ценность | Комментарий |
|---|---|---|---|
| Турниры сеткой на выбывание | 🟡 | ⭐⭐ | С расписанием и трансляцией результатов |
| Сезоны и лиги (бронза→золото) | 🟡 | ⭐⭐⭐ | Сброс кубков раз в сезон — держит мотивацию долго |
| Командные режимы: эстафеты, клановые войны | 🔴 | ⭐⭐ | Развитие клубов из V3 |
| Другие дисциплины: 2x2, 4x4, OH, пирамидка | 🟡 | ⭐⭐ | Расширяет аудиторию |
| Blindfolded (сборка вслепую) | 🟡 | ⭐ | Зрение проверяет только итог — интересная задача |
| Зрительский режим (смотреть чужую дуэль) | 🔴 | ⭐ | Нужна аудитория, чтобы имело смысл |
| Реплеи с записью таймлайна | 🟡 | ⭐⭐ | Основа для разборов и шэринга |

| Фича | Сложн. | Ценность | Комментарий |
|---|---|---|---|
| **Поддержка Bluetooth-кубов (GAN, GoCube)** | 🔴 | ⭐⭐⭐ | Куб шлёт повороты по BLE → таймер точен до мс, каждый поворот известен. Мощнейшая связка с разбором по фазам — аналитика каждого хода |

## Монетизация (если и когда захочешь)

**Принцип:** соревновательное ядро — всегда бесплатно. Платный доступ к рейтингу убьёт комьюнити. Монетизируем украшательства и продвинутую аналитику.

| Что | Модель |
|---|---|
| Темы, скины таймера, звуки | Разовая покупка / косметика |
| Расширенная аналитика фаз, история без лимитов | Pro-подписка |
| Приватные турниры для клуба | Pro / командный тариф |

---

## Если выбирать одну фичу-визитку для V2/V3
**Разбор сборки по фазам** (🔴 ⭐⭐⭐). Причины:
1. Невозможен на обычных таймерах (qqtimer, cstimer) — реальная причина уйти к тебе
2. Использует именно твой ML/CV-навык — то, что делает проект уникальным
3. Идеально сочетается с поддержкой Bluetooth-кубов позже (аналитика каждого поворота)

## Дисциплина роадмапа
- Ни одна фича отсюда не начинается, пока MVP (6 этапов) не задеплоен и не работает у реальных людей
- Каждая версия V2/V3/V4 — это тоже «сначала одна фича до конца, потом следующая»
- Новые идеи → всегда сюда, в бэклог, а не в текущую работу
