# Design Reference — макеты дизайн-борда

Скрины доски «ход 2» (блоки 2a–2h), из которых выжат [design-system.md](../design-system.md).
Спецификация — источник истины; эти картинки — визуальный референс настроения.

**Утверждено:** графический язык **В2 «Чистая сетка»** как база + **стикеры В1** в
моменты праздника; таймер **Т1** (Rubik 900 + цветная точка); логотип Л1 (знак 2×2 + слово).
