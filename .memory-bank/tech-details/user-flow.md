## 1. Первый визит и регистрация

```mermaid
flowchart TD
    A(["Пользователь открыл сайт"]) --> B["Лендинг: что это,<br/>как работает, CTA"]
    B --> C{"Есть аккаунт?"}
    C -->|Да| LOGIN[["Флоу входа → §2"]]
    C -->|Нет| D{"Способ регистрации"}
    D -->|Google| E["OAuth Google"]
    E --> E2["Аккаунт создан,<br/>почта уже подтверждена"]
    D -->|Email| F[/"Email + пароль + ник"/]
    F --> G{"Валидация:<br/>email свободен, пароль ок,<br/>ник свободен?"}
    G -->|Нет| F
    G -->|Да| H["Письмо со ссылкой<br/>подтверждения"]
    H --> I{"Перешёл по ссылке?"}
    I -->|Нет, письмо не пришло| J["Отправить повторно<br/>(лимит по времени)"]
    J --> I
    I -->|Да| K["Почта подтверждена"]
    E2 --> ONB
    K --> ONB["Онбординг: 3 экрана —<br/>1) нужен кубик 3x3 и камера<br/>2) как проходит ритуал сборки<br/>3) проверка камеры"]
    ONB --> CAMOK{"Камера работает,<br/>руки детектятся?"}
    CAMOK -->|Да| HOME(["Главная"])
    CAMOK -->|Нет| FIX["Подсказки: разрешить камеру,<br/>свет, положение рук"]
    FIX --> CAMOK
```

**Важно:** онбординг с проверкой камеры обязателен при первом входе — иначе человек попадёт в дуэль и завалит её из-за неработающего зрения. Пропустить можно, но с предупреждением.

## 3. Главная (лобби)

Что видит залогиненный игрок:

- **Шапка:** лого, кубки 🏆, аватар → меню (профиль, настройки, выход)
- **Центр:** три большие кнопки — «Дуэль Фаст», «Дуэль Ao5», «Турнир недели»
- **Турнир недели:** статус (участвовал / нет), место в таблице, до конца недели N дней
- **Сбоку:** мини-лидерборд топ-10, счётчик игроков онлайн

```mermaid
flowchart TD
    H(["Главная"]) --> F1["Дуэль Фаст"] --> MM[["Матчмейкинг → §4"]]
    H --> F2["Дуэль Ao5"] --> MM
    H --> T["Турнир недели → §6"]
    H --> P["Профиль → §7"]
    H --> LB["Лидерборд"]
    H --> S["Настройки → §8"]
```

## 4. Матчмейкинг дуэли

```mermaid
flowchart TD
    A(["Нажал «Дуэль»"]) --> M{"Режим уже выбран<br/>(Фаст / Ao5)"}
    M --> Q["Поиск соперника:<br/>кубки ± диапазон"]
    Q --> W{"Найден за 60 сек?"}
    W -->|Да| ROOM(["Комната дуэли → §5"])
    W -->|Нет| E{"Что делать?"}
    E -->|Расширить поиск| Q2["Диапазон кубков шире"] --> W
    E -->|Режим «риск»| R["Поиск среди игроков<br/>с бОльшими кубками"] --> W
    E -->|Отмена| H(["Главная"])
    Q -.->|Отменить поиск| H
```

**Правила:**
- Пока идёт поиск — показываем счётчик и кнопку отмены
- «Риск» доступен и сразу: отдельный переключатель до старта поиска
- Оба игрока попадают в комнату одновременно; у обоих один и тот же скрамбл от сервера

## 5. Комната дуэли — главный флоу продукта

### 5.1 Полный ритуал (одна сборка)

> **Поправка 1 (утв. фича):** шаг «перемешивает по скрамблу» = по **визуальной
> пошаговой инструкции** (картинки-со-стрелками, по умолчанию) ИЛИ нотации (по
> выбору игрока). Ветка несовпадения при проверке камерой получает выход
> «вернуться к инструкции». См. [feature-scramble-visual](../product-overview/feature-scramble-visual.md).
>
> **Поправка 2 (утв. фича, порядок ритуала):** первым шагом игрок показывает
> **СОБРАННЫЙ** кубик (калибровка/быстрая подстройка по профилю + подтверждение
> честного старта) — ДО выдачи скрамбла. Диаграмма ниже начинается со скрамбла для
> краткости, но канонический порядок: `CALIBRATE_SOLVED → SCRAMBLE_SHOWN →
> SCRAMBLE_VERIFY → READY → SOLVING → STOPPED → SOLVE_VERIFY`.
> См. [feature-cube-profiles](../product-overview/feature-cube-profiles.md).

```mermaid
flowchart TD
    A(["Оба игрока в комнате"]) --> B["Экран: скрамбл (нотация + картинка),<br/>своя камера, статус соперника"]
    B --> C["Игрок перемешивает кубик<br/>по скрамблу"]
    C --> D["Показывает 6 граней камере<br/>(подсказки: какую грань повернуть)"]
    D --> E{"Состояние совпало<br/>с эталоном скрамбла?"}
    E -->|Нет| E2["Показать, какая грань не совпала.<br/>Исправить и показать снова"]
    E2 --> D
    E -->|3 неудачи подряд| E3["Кнопка «перечитать заново» +<br/>подсказка про свет/калибровку"]
    E3 --> D
    E -->|Да| F["Статус: ГОТОВ ✅<br/>Кладёт две руки на стол"]
    F --> G{"Обе руки на столе,<br/>кубик на столе?"}
    G -->|Нет| F
    G -->|Да| H{"Соперник тоже готов?"}
    H -->|Нет| W["Ожидание. Видим статус соперника:<br/>перемешивает / проверка / готов"]
    W --> H
    H -->|Да| CD["Синхронный отсчёт 3-2-1<br/>(сервер шлёт старт обоим)"]
    CD --> GO["🟢 СТАРТ — таймер пошёл.<br/>Игрок взял кубик, собирает"]
    GO --> STOP{"Обе руки вернулись<br/>на стол?"}
    STOP -->|Нет| GO
    STOP -->|Да| TS["Таймер СТОП (время зафиксировано)"]
    TS --> V["Показать кубик камере"]
    V --> OK{"Кубик собран?"}
    OK -->|Да| RES["Результат отправлен на сервер<br/>+ ключевые кадры на валидацию"]
    OK -->|Нет| DNF["DNF — сборка не засчитана"]
    RES --> FIN(["Экран результата → 5.3"])
    DNF --> FIN
```

### 5.2 Режим Ao5

Ритуал 5.1 повторяется 5 раз подряд. Между сборками — пауза до 30 сек («следующий скрамбл»). После пятой: отбрасываем лучшее и худшее, среднее из трёх → результат Ao5. DNF в одной сборке = автоматически «худшее время». Два DNF = DNF всей серии.

### 5.3 Экран результата

```mermaid
flowchart TD
    A(["Оба закончили<br/>(или таймаут/DNF)"]) --> B["Сервер валидировал кадры и тайминги"]
    B --> C{"Валидация прошла<br/>у обоих?"}
    C -->|Да| D["Экран: время обоих,<br/>победитель, кубки: +N / −M"]
    C -->|У кого-то нет| E["Его результат → rejected,<br/>победа сопернику"]
    E --> D
    D --> F{"Дальше?"}
    F -->|Реванш| G{"Соперник согласен?<br/>(запрос, 30 сек)"}
    G -->|Да| ROOM(["Новая комната, тот же соперник"])
    G -->|Нет/таймаут| H(["Главная"])
    F -->|Новый соперник| MM(["Матчмейкинг"])
    F -->|Выход| H
```

### 5.4 Ветки ошибок в дуэли (обязательно обработать!)

```mermaid
flowchart TD
    subgraph DISCONNECT["Соперник отвалился"]
        A{"На каком этапе?"} -->|До старта таймера| B["Ждём 60 сек →<br/>не вернулся: дуэль отменена,<br/>кубки не меняются, → матчмейкинг"]
        A -->|Во время сборки| C["Ждём его финиша до таймаута<br/>(лимит сборки, напр. 10 мин).<br/>Не вернулся → тебе победа"]
    end
    subgraph SELF["У тебя проблемы"]
        D["Пропала камера / связь"] --> E["Пауза до старта — можно вернуться.<br/>После старта — таймер НЕ останавливается<br/>(иначе чит). Вылет = DNF"]
        F["Кубик упал со стола"] --> G["Таймер идёт — как в реальных<br/>соревнованиях. Поднять и продолжить"]
        H["Хочу сдаться"] --> I["Кнопка «Сдаться» → DNF,<br/>победа сопернику"]
    end
```

## 6. Турнир недели

```mermaid
flowchart TD
    A(["Открыл «Турнир недели»"]) --> B{"Уже участвовал<br/>на этой неделе?"}
    B -->|Да| C["Экран: твоё время, твоё место,<br/>таблица недели, таймер до конца"]
    B -->|Нет| D["Экран: описание, скрамбл скрыт,<br/>кнопка «Сделать попытку»<br/>⚠️ Попытка одна!"]
    D --> E{"Подтвердил?"}
    E -->|Нет| A
    E -->|Да| F[["Ритуал сборки (соло, без соперника)<br/>тот же флоу, что 5.1"]]
    F --> G{"Итог"}
    G -->|Время| H["Результат в таблицу недели"]
    G -->|DNF| I["DNF в таблицу —<br/>попытка потрачена"]
    H --> C
    I --> C
    C -.->|Конец недели, cron| J["Таблица финализируется,<br/>кубки по местам,<br/>новый скрамбл недели"]
```

**Правила:** одна попытка в неделю на игрока; скрамбл виден только после подтверждения попытки (иначе можно натренировать); отвал/перезагрузка после показа скрамбла = попытка потрачена (анти-чит).

## 8. Настройки

| Раздел | Что можно |
|---|---|
| Аккаунт | Сменить ник (лимит: раз в N дней), аватар |
| Безопасность | Сменить пароль, привязать/отвязать Google, выйти со всех устройств |
| Камера | Тест камеры, детект рук, **калибровка цветов кубика** (снять эталон своих 6 цветов при своём освещении) |
| Опасная зона | Удалить аккаунт (подтверждение паролем) |

Калибровка цветов — важный экран: у всех разные кубики и свет; сохранённый цветовой профиль сильно поднимет точность зрения.

## 10. Чеклист состояний, которые легко забыть

- [ ] Пустые состояния: история сборок пуста, лидерборд пуст (первая неделя), никого онлайн для матчмейкинга
- [ ] Загрузка/ожидание: поиск соперника, валидация кадров сервером, «соперник ещё собирает»
- [ ] Ошибки сети: WebSocket отвалился и переподключился — восстановить состояние комнаты
- [ ] Камера: доступ запрещён / камеры нет / занята другим приложением
- [ ] Мобильный браузер: минимум — экран «играй с ноутбука/ПК» (камера + кубик + две руки на телефоне неудобно) — решить, поддерживаем ли в MVP
- [ ] Один аккаунт с двух вкладок/устройств одновременно — запретить вторую активную дуэль
- [ ] Rate limits: повторная отправка писем, попытки входа, спам матчмейкингом
