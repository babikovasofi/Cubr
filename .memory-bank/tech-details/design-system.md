# DESIGN-SPEC.md — Cubr · «Плейфул-поп»

Спецификация утверждённого дизайна для воспроизведения без картинок.
Источник: доска «ход 2» (блоки 2a–2h) файла «CubeDuel Направления.dc.html».
Утверждённые вариации: графический язык **В2 «Чистая сетка» как база + стикеры В1 в моменты праздника**; таймер **Т1 «Rubik 900 + цветная точка»** (именно он использован на экранах); логотип **Л1 «Знак 2×2 + слово»** (*дозаполнено: Л1 — единственный, использованный на макетах экранов*).

---

## 1. ХАРАКТЕР ДИЗАЙНА

Тёплый, дружелюбный и точный. База интерфейса — спокойная кремовая «бумага» с чернильным текстом; шесть цветов кубика Рубика — строго дозированные акценты с закреплёнными ролями. Настроение — «игра с друзьями», а не киберспорт-финал: скругления, стикеры с жёсткой чёрной тенью, лёгкие повороты — но только в моменты события (старт, победа, ачивка). Рабочие экраны сдержанны: мотив сетки 3×3 задаёт структуру, цвет живёт в деталях (точка таймера, статус соперника, счёт раундов). Камера игрока — самое яркое пятно экрана, интерфейс вокруг неё всегда нейтрален. Таймер — сердце продукта: всегда жирный, табличные цифры, спокойная подложка. Узнаваемость дают: чернильная обводка 2px + смещённая жёсткая тень, мини-сетки 3×3 как живые индикаторы, бейджи-пилюли.

**Всегда так:**
1. Правило 90/8/2: ≥90% экрана — нейтральная база, ~8% — один ведущий акцент (обычно `primary` синий), ≤2% — «праздник» из нескольких цветов кубика.
2. Таймер: вес 900, `tabular-nums`, на нейтральной подложке, минимум 64px на десктопе.
3. Вокруг области камеры — только нейтральные токены (фон, поверхность, линии); цветные элементы — на расстоянии ≥16px от рамки видео.
4. Стикер-элементы (ачивки, «ПОБЕДА!», номер 1 в таблице) — обводка 2px `ink`, тень `shadow-sticker`, поворот от −6° до +6°.
5. У каждого цвета кубика одна роль (см. §2); цвет вне роли не используется.

**Никогда так:**
1. Никогда не более 2 ярких цветов кубика в одном компоненте (исключение: конфетти, знак логотипа, паттерн-«праздник»).
2. Никогда цветной текст на цветной заливке (жёлтый на оранжевом и т.п.) — текст только `ink` или белый, контраст ≥4.5:1.
3. Никогда не красить фоны экранов и крупные панели в цвета кубика — они для деталей и моментов.
4. Никогда не вращать и не анимировать рабочие элементы (поля, таблицы, таймер в фазе сборки) — повороты только у стикеров-событий.
5. Никогда не «сюсюкать» в копирайте и не сыпать эмодзи: допустим один эмодзи 🏆 в бейдже кубков; поражение — тихое, без красных плашек.

## 4. ГЕОМЕТРИЯ И СЕТКА

**Радиусы:** `sm` 8px (мини-плитки, чипы статуса) · `md` 12px (поля, тосты, внутренние блоки) · `lg` 16px (карточки, панели) · `xl` 20px (крупные секции) · `full` 9999px (кнопки, бейджи-пилюли). Плитки знака/ачивок: 10–14px в зависимости от размера (≈ 22% стороны).

**Тени (CSS):**
- `shadow-sticker`: `3px 3px 0 var(--ink)` — стикеры, hover кнопок, ачивки.
- `shadow-sticker-lg`: `4px 4px 0 var(--ink)` — карточка победы, крупные стикеры.
- `shadow-soft`: `0 6px 12px rgb(34 30 23 / 0.10)` — модалки, тосты (*дозаполнено*).
- Обычные карточки — без тени, только граница `line`.

**Spacing (px):** 4, 8, 12, 16, 20, 24, 28, 32, 40, 48. Паддинг карточки 18–20px; между карточками 12–16px; паддинг секции 28px.

**Контент:** max-width 1120px, центр; gutter 16px mobile / 24px desktop. Брейкпоинты tailwind по умолчанию (sm 640, md 768, lg 1024, xl 1280).

**Мотив 3×3 (закодить точно):**
- *Мини-сетка-индикатор*: 3×3 квадратов 8×8px, gap 2px, radius 2px; «пустые» ячейки `line`, активные — цвет статуса (§5.8).
- *Паттерн-разделитель* (пустые состояния, декор): сетка из квадратов 10×10px, gap 2px, заполнение цветом с opacity 1, не более 2 цветных ячеек из 9, остальные `line`.
- *Рамка-сетка* (иллюстрации В2): ячейки 34×34px, gap 4px, заливка `line`; акцентные ячейки `primary`/`warning`; пустая ячейка — `border: 2px dashed var(--faint)`.
- *Линии-сетки*: 1px `line`, шаг 34px, без прозрачности.

## 5. КОМПОНЕНТЫ

### 5.1 Кнопка основная
- Высота 44px (паддинг 10px 18px), radius `full`, шрифт Rubik 800 13–15px.
- Default: фон `primary`, текст `#FFFFFF`, граница `2px solid ink`, без тени.
- Hover: фон `primary-press`, `translate(-2px,-2px)`, тень `shadow-sticker`; переход 150ms `cubic-bezier(0.34,1.56,0.64,1)`.
- Active: возврат в `translate(0,0)`, тень исчезает, 100ms.
- Disabled: фон `surface-2`, текст `faint`, граница `2px solid line`.
- Focus: кольцо `2px primary`, offset 2px.

### 5.2 Кнопка вторичная
Как 5.1, но фон `surface`, текст `ink`, граница `2px solid ink`. Hover: фон `surface-2` + сдвиг/тень как у основной. Disabled — как 5.1.

### 5.3 Кнопка опасная
Как 5.1, фон `danger`, текст белый. Используется только для «Сдаться» и разрушающих действий.

### 5.4 Поле ввода
- Высота 42px, паддинг 9px 14px, radius `md`, фон `surface`, шрифт 13–15px/400, плейсхолдер `faint`.
- Default: граница `2px solid line`. Focus: граница `2px solid primary` (без кольца). Error: граница `2px solid danger` + подпись 11px/700 `danger` через 3px снизу. Disabled: фон `surface-2`, текст `faint`.

### 5.5 Карточка
Фон `surface`, граница `1px solid line`, radius `lg`, паддинг 18px. Кликабельная — hover: граница `2px ink` (компенсировать паддингом −1px), 120ms linear. Карточка-«момент» (победа): граница `2px ink`, тень `shadow-sticker-lg`.

### 5.6 Бейдж кубков

- Дельта-минус: фон `surface`, граница `1px line`, текст `danger`, «▼ −12» (тихий).

### 5.7 Ачивка (стикер)

## 7. АНИМАЦИИ И МИКРО-ВЗАИМОДЕЙСТВИЯ

Общий easing «пружина»: `cubic-bezier(0.34,1.56,0.64,1)` (далее — spring). Всё 300–800ms. `prefers-reduced-motion` — заменять на fade 150ms.

| # | Триггер | Что происходит | Длит. | Easing |
|---|---|---|---|---|
| 1 | Отсчёт 3-2-1 | плитка 52px с цифрой падает сверху (−40px→0), scale 0.6→1.1→1, поворот ±6°; цвета: 3 `warning`, 2 `live`, 1 `danger` | 3×600ms | spring |
| 2 | «GO!» / старт | плитка `success` 60px, scale 0→1.2→1 + вспышка фона `success` opacity 0.15→0 | 500ms | spring |
| 3 | Стоп (финиш) | точка таймера `faint`→`success`, цифры scale 1→1.06→1 | 300ms | ease-out |
| 4 | Победа | конфетти: 24 квадрата 7–10px 6 цветов, падение с вращением, «прилипают» к низу карточки; плашка «ПОБЕДА!» шлёпается: scale 1.3→1, rotate −8°→−2° | 1500ms / 400ms | ease-in (падение) / spring |
| 5 | Поражение | только fade-in карточки | 200ms | ease-out |
| 6 | Начисление кубков | «+24» вылетает из карточки (translateY −24px, fade), бейдж-одометр крутит цифры, вспышка `warning` + scale 1→1.15→1 | 800ms всего, пульс 250ms | ease-out / spring |
| 7 | Ачивка | стикер прилетает rotate 24°→−8°→3°, scale 0.6→1.1→1, «приклеивается» с wobble (±2°, 2 колебания), подпись fade после | 700ms + 200ms | spring |

| 9 | Hover кнопки | сдвиг −2px,−2px + тень | 150ms | spring |
| 10 | Статусы соперника | по §5.8 (мигание/пульс) | 400–1200ms | steps / ease-in-out |

## 8. ИЛЛЮСТРАЦИИ И ИКОНКИ

**Иконки**: база — **Lucide** (ближайшая по духу: скруглённые окончания, обводка 2px). Настройка: stroke 2px, цвет `ink`, размер 20/24px; на плитке-подложке `surface-2` 40×40px radius 10px. Акцентная иконка — один цвет кубика, не более одной цветной на компонент.

**Иллюстрации** — стиль В2 «чистая сетка»: композиции из квадратов сетки 3×3 (ячейки 34px, gap 4px), заливки `line` + 1–2 акцентные ячейки, пустая ячейка `2px dashed faint` со знаком «?»; подпись 11px/600 `muted`. Без персонажей, без градиентов, без рисованных SVG-сцен.

Нужные иллюстрации:
1. «Соперник не найден» — сетка 3×3, центр пустой dashed с «?», подпись «место соперника свободно».
2. «Нет соединения» — сетка, где 4 ячейки «отвалились» вниз со сдвигом 4–8px, все `line` (*дозаполнено*).
3. «Пустой список дуэлей» — одинокая плитка `primary` + подпись «сыграй первую дуэль» (*дозаполнено*).
4. «Камера недоступна» — рамка-гид кубика dashed + ячейка `danger`, подпись «разреши доступ к камере» (*дозаполнено*).
5. Онбординг (3 шага): а) плитка+камера — «покажи кубик»; б) две ладони-прямоугольника в зонах — «руки на стол»; в) плитка `success` — «собирай!» (*дозаполнено*).
